# agent-browser

Headed browser automation CLI.

- command: `/Users/ai/bin/agent-browser`
- registry: `/Users/ai/tools/agent-browser`
- npm package: `/Users/ai/tools/payloads/npm/agent-browser`
- source: `/Users/ai/tools/payloads/source/agent-browser`
- browser environment: `/Users/ai/state/browser`
- config: `/Users/ai/state/browser/tools/agent-browser/config`
- scoped home: `/Users/ai/state/browser/tools/agent-browser/home`

Use this for repeatable browser automation. Use Computer Use when auth, popups, or visible Mac app state need hands on the real desktop.
