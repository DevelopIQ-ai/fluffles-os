# fluffles-site

Deployment helper for the Fluffles personal website.

- command: `/Users/ai/bin/deploy-fluffles-site`
- source: `/Users/ai/projects/fluffles-site`
- production: `https://fluffles-site.vercel.app`
- deploys through: `/Users/ai/bin/vercel`

Use this command from anywhere to validate the site and deploy it to production.
