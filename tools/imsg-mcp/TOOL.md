# imsg-mcp

iMessage / SMS CLI and MCP server for macOS Messages.

- command: `/Users/ai/bin/imsg`
- registry: `/Users/ai/tools/imsg-mcp`
- npm package: `/Users/ai/tools/payloads/npm/imsg-mcp`
- state: `/Users/ai/state/tools/imsg-mcp`
- local data source: `/Users/ai/Library/Messages/chat.db`

Use `imsg doctor` after install or permission changes. Reading requires Full Disk Access for the app or terminal process running the harness. Sending requires Messages.app and macOS Automation permission.
